# Swim lesson booking

A simple, responsive Vue 3 welcome page with separate employee and client login choices.

## Run locally

Install dependencies with `npm install`, then start the development server with `npm run dev`.

Create a production build with `npm run build`.

## Deploy to GitHub Pages

The GitHub Actions workflow in `.github/workflows/deploy-pages.yml` builds and deploys the site on pushes to `main` (or when run manually). In the repository settings, open **Pages** and set the build and deployment source to **GitHub Actions**. The published site will be available at `https://anglcode.github.io/scheduler-demo/` after the first successful deployment.
